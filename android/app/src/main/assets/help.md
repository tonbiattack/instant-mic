# instant-mic の使い方

スマホに向かって話すと、同じ Wi-Fi につないだ Windows PC の入力欄にそのまま文字が入ります。音声は認識サービス以外へ送らず、PC 側では認証済みの操作だけを受け付けます。

## 基本の流れ

1. PC で受信アプリ（instant-mic.exe）を起動する
2. スマホのアプリを開き、一覧に出た PC をタップする
3. PC の画面に確認が出るので「はい」を押す
4. 以後はアプリを開くだけで自動でつながる

ペアリングは 1 回だけです。2 回目以降は PC を起動しておけば、アプリを開いた時点で接続します。

## 話し方

1. PC の入力したい欄（メモ帳、ブラウザ、エディタなど）をクリックしてフォーカスする
2. アプリの「タップして話す」を押して話す
3. 話し終えると、確定したテキストが PC に入力される

連続音声入力がオンのときは、無音を挟んで話し続けてもそのまま次の発話が入力されます。止めるときだけもう一度タップします。

## 音声コマンド

接頭語（既定は「コマンド」）のあとに区切り（「、」や空白）を置いて続けると、キー操作として実行されます。**言い切りの形で一致したときだけ**動くので、文中の「送信」では実行されません。

| 話しかた | 操作 |
| --- | --- |
| コマンド、送信 / エンター | Enter |
| コマンド、改行 | Shift+Enter |
| コマンド、削除 / バックスペース | Backspace |
| コマンド、前の単語削除 | Ctrl+Backspace |
| コマンド、行削除 | 現在行を削除（Home → Shift+End → Delete） |
| コマンド、デリート | Delete |
| コマンド、上 / 下 / 左 / 右 | ↑ / ↓ / ← / → |
| コマンド、コピー / 貼り付け / 切り取り | Ctrl+C / Ctrl+V / Ctrl+X |
| コマンド、やり直し | Ctrl+Y |
| コマンド、タブ切り替え | Ctrl+Tab |
| コマンド、取り消し | Ctrl+Z |
| コマンド、全選択 | Ctrl+A |
| コマンド、言い直し | 直前に PC へ入力したテキストを取り消す |

キー名をカタカナで言っても認識されます（「コマンド、エンター」「コマンド、アップ」など）。「上」が通りにくいときは「アップ」を使ってください。

### 同じ操作を繰り返す

「コマンド、3回削除」「コマンド、削除3回」「コマンド、三回削除」のように回数を添えると、その回数だけ実行します。上限は 5 回で、対象は削除・デリート・カーソル移動・前の単語削除です。

### 言い直し

「コマンド、言い直し」で、直前に PC へ入力したテキストを文字数ぶん Backspace で取り消します。

- 対象は直前のテキスト入力だけです。キー操作（送信・削除など）のあとは取り消せません
- 取り消しは 1 回限りです。同じ入力を二重に消すことはありません
- 受信側が記録した文字数と一致したときだけ削除します。合わないときは何も消さずに失敗を返します

### 行削除について

「行削除」はアプリごとにショートカットが違うため、既定では Home → Shift+End → Delete で行全体を選んで消します。VS Code などはこの操作で行が消えますが、ソフトによっては行末の文字だけが消えます。合わないときはカスタムコマンドで置き換えてください。

## 句読点と記号

文章の中で記号の名前を話すと、記号として入力されます。コマンドと違い、文の一部として普通に使えます。

| 話しかた | 入力される文字 |
| --- | --- |
| まる | 。 |
| てん | 、 |
| はてな | ？ |
| びっくりまーく | ！ |
| ころん | ： |
| せみころん | ； |
| すらっしゅ | / |
| かっこ 〜 かっことじ | （ 〜 ） |
| かぎかっこ 〜 かぎかっことじ | 「 〜 」 |

例：「これで合ってる はてな」→「これで合ってる？」。

- 単独で使う記号は、文末・空白・既存の句読点の直前にあるときだけ変換します。「まるで違う」「てんぷら」「かっこいい」は変換しません
- かっこ類は開きと閉じがそろっているときだけ変換します
- 認識結果がすでに句読点で終わっている場合は重複させません

## 設定

アプリ上部の「コマンド」から設定画面を開けます。

| 設定 | 内容 |
| --- | --- |
| 連続音声入力 | 停止するまで、発話ごとに自動で聞き取りを再開します |
| 開始・終了の振動 | 準備完了で 1 回、聞き取り終了で 2 回振動します |
| 起動したらすぐ話す | アプリを開いた時点で聞き取りを始めます |
| 送信・削除の前に確認する | 「送信」「削除」などを実行する前に確認ボタンを出します |
| 認識方式 | 端末内を優先（通信不要）か、システム既定（ネットワーク利用可）を選びます |
| 話し終わりまでの待ち時間 | 短め 800ms / 標準 1,200ms / 長め 2,000ms |
| 開発用語の辞書 | GitHub・Codex・SQL・Go などの誤変換を直します |
| ひらがなで入力する | 漢字に変換せず、読みのまま入力します |
| 入力の反映 | 確定してから入力（既定）か、区切りごとに早めに入力 |

### ひらがなで入力する

漢字に変換せず読みのまま入力します。「改行」と「開業」のような漢字の選び間違いが原理的に消えるので、AI への指示書きに向いています。カタカナ・英数字・URL・記号はそのまま残ります。

例：今日は会議があります → きょうはかいぎがあります

### 用語辞書の追加

「誤って認識される表記」を話すと「正式な表記」で入力されるように登録できます。誤認識側は日本語で指定してください（英数字を対象にするとコードや URL を壊すため）。

### カスタム音声コマンド

「コマンド、フレーズ」で、登録したキー操作を実行できます。

- 例：「AIに送信」→ `ctrl+enter`
- キーは `ctrl+enter`、`home>shift+end` のように指定します。`>` で最大 8 ステップの連続操作になります
- Ctrl / Shift / Alt / Win と、英数字・F1〜F24・Enter/Tab/Escape/Backspace/Delete/Insert/Space/矢印/Home/End/PageUp/PageDown が使えます
- 標準コマンドと重複するフレーズは登録できません
- Ctrl+Alt+Delete は Windows のセキュリティ画面を開くため、登録できません

## すぐ話す

- Quick Settings（通知シェードのタイル）に「音声入力」を追加すると、タイルをタップするだけでアプリが開いて聞き取りが始まります
- 設定の「起動したらすぐ話す」をオンにすると、アプリを開いた時点で聞き取りが始まります
- どちらも画面を離れると停止します（バックグラウンドでは録音しません）

## 困ったとき

### PC が見つからない

- PC とスマホが同じ Wi-Fi につながっているか確認してください
- PC 側の受信アプリが起動しているか確認してください
- 接続できないときは、Windows ファイアウォールで instant-mic.exe の受信を許可してください
- 自動検出が使えないネットワークでは、QR コードを読み取るか、IP アドレスと 6 桁コードを手動で入力してください

### 「再ペアリングが必要です」と出る

別の PC を検出したか、PC の証明書が変わったときに表示されます。勝手に接続せずに止めています。「ペアリングし直す」を押して、もう一度ペアリングしてください。

### 文字が入力されない

- PC 側で入力したい欄をクリックしてフォーカスしてください。フォーカスがないと入力できません
- 管理者権限で動いているアプリには入力できません（UAC を回避する仕組みはありません）
- 接続カードの「入力先」が赤字のときは、その理由が表示されています

### 認識されない・誤変換が多い

- 設定の「認識方式」を切り替えて、同じ文を読み比べてください
- 話し終わりまでの待ち時間を「長め」にすると、発話の途中で切れにくくなります
- 「開発用語の辞書」を有効にすると、GitHub などの誤変換が減ります
- 漢字の選び間違いが多いときは「ひらがなで入力する」を試してください

### 音声はどこへ送られるか

Android 13 以降で端末内認識が使える場合は、オフライン認識を優先します。使えない端末では Google などのクラウド認識になり、音声が送信されます。アプリは音声を保存しません（録音ファイルも履歴も持ちません）。

## 制限

- 同じ LAN の中だけで使えます。インターネット越しの接続は対象外です
- 画面を開いている間だけ録音します。バックグラウンドでの常時待機は対象外です
- 管理者権限で動くアプリや一部のゲームには入力できません
- Enter の意味はアプリごとに違います（送信 / 改行）。カスタムコマンドで置き換えられます
